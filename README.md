# protocol · Launch Lab 21

Рабочий прототип инкубатора: команда проходит модули по шаблонам, ответы сами складываются в one-pager.

Кампусы демо: **Ташкент** и **Самарканд**. У пира отдельно `nickname` (Intra) и `name` (ФИО).

## Запуск

```bash
npm i
npm run dev
```

http://localhost:5173 — данные в `localStorage`. Если экран старый: «Сбросить демо» или `Cmd+Shift+R`.

Пароль демо для всех сидов: `21`

## Демо

**Участник:** `stockcol` / `21`  
Открой **PeerCV** → заполни следующий модуль → **Сохранить ответ** → **One-pager**. Чужие проекты закрыты.

**Модератор:** тот же логин, роль «модератор»  
Панель «Модерация»: фильтр по кампусу, прогресс, ответы, one-pager.  
**IntraMatch** (`dilnoza`) — полный one-pager. **Mentora** (`oybekcv`) — тоже закрыт полностью.

Другие ники: `nilufer`, `bekzodj`, `madinaml`, `dilnoza`, `oybekcv` …

## Обязательный сценарий

1. Создать или открыть свой проект  
2. Пройти модуль (поля шаблона)  
3. Сохранить ответ  
4. Увидеть его в one-pager
