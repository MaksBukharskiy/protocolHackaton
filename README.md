# Сквад 21

Кампусная доска для пиров School 21: навыки, проекты и поиск команды. Локальный прототип для хакатона.

## Запуск

```bash
npm i
npm run dev
```

Открой адрес из терминала (обычно http://localhost:5173). Данные живут в `localStorage`, бэкенд не нужен.

## Демо

1. Войди как `rwood`
2. В ленте поставь фильтр «ищем фронтенд»
3. Открой **Mentora** или **IntraMatch** → «Хочу в команду»
4. Создай свой проект
5. В «Пиры» найди ML (`npetrov` / `yegorov`)

Кнопка «сбросить демо» на экране входа возвращает сиды.
