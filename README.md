# protocol · Launch Lab 21

Рабочий прототип инкубатора: команда проходит модули по шаблонам, ответы сами складываются в one-pager.

## Запуск

```bash
npm i
npm run dev
```

http://localhost:5173 — данные в `localStorage`. Если экран старый, `Cmd+Shift+R` и «Сбросить демо».

## Демо

**Участник:** `rwood` / `21`  
Открой **PeerCV** → заполни шаблон модуля «Решение» → **Сохранить ответ** → **One-pager**. Чужие проекты закрыты.

**Модератор:** тот же логин, роль «модератор»  
Панель: все команды, прогресс, ответы, шаблоны программы. **IntraMatch** — полный one-pager.

## Обязательный сценарий

1. Создать или открыть свой проект  
2. Пройти модуль (поля шаблона)  
3. Сохранить ответ  
4. Увидеть его в one-pager
